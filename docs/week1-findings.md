# Week 1 — ผลทดสอบ Live API

## 2026-10-09 · Smoke test จาก Node (ไม่มีไมค์)
token จาก `/api/token` → `ai.live.connect` (v1alpha) → ส่ง "(ผู้ใช้รับสายแล้ว)"

| รายการ | ผล |
|---|---|
| เชื่อมต่อด้วย ephemeral token (v1alpha) | ✅ ผ่าน |
| config ที่ล็อกใน token (system prompt, transcription, voice) มีผล โดย client ส่งแค่ `responseModalities` | ✅ ผ่าน — AI เล่นบทตาม prompt |
| พูดประโยคเปิดตามบท ภาษาไทย | ✅ ตรงกับ `openingLine` แทบทุกคำ |
| output transcription | ✅ ได้ข้อความไทย |
| เวลาถึงเสียงแรก (ส่ง cue → audio chunk แรก) | ~705 ms |
| รูปแบบเสียงขาออก | `audio/pcm;rate=24000` ตรงตามเอกสาร |
| ความยาวประโยคเปิด | ⚠️ ~14.5 วินาที ยาวไป → ย่อ openingLine แล้ว เหลือ ~6 วินาที (เสียงแรก 675 ms) และจบด้วยคำถามให้ผู้เล่นตอบ |
