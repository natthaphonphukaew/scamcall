### ข้อสังเกตจาก transcript
1. **input transcription เพี้ยนตอนพูดสั้นๆ** — ถอดเป็นภาษาอังกฤษมั่ว ("A B", "Aha.", "Adela") → ตอนวิเคราะห์ X-Ray ต้องไม่เชื่อ turn ผู้เล่นที่สั้น/ไม่ใช่ภาษาไทยมากนัก และอาจเพิ่ม hint ภาษาไทยให้ transcription ถ้า API รองรับ
2. **เวลา `t` ของผู้เล่นมักเท่ากับของคนร้าย** (0:27/0:27, 0:51/0:51) — input transcription มาถึงตอนพูดจบ ไม่ใช่ตอนเริ่มพูด → ไทม์ไลน์ X-Ray ควรเรียงตามลำดับ turn ไม่ใช่ตาม `t` อย่างเดียว
3. **"โอนสายไปผู้กำกับ" ยังเป็นเสียงเดิม** — Live API ใช้เสียงเดียวต่อ session; ยอมรับได้ (ผู้กำกับยังอ้างตัวชัด) อาจปรับในพรอมต์ให้เปลี่ยนน้ำเสียง/จังหวะพูด
4. ผลลัพธ์: **ใช้ Live API ต่อ ไม่ต้องใช้แผนสำรอง**
