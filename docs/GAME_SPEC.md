# ScamCall: Campus — Game Spec

> เวอร์ชัน 0.1 · 2026-10-11 · ต่อยอดจาก `docs/SPEC.md` (ระบบสาย/X-Ray/คะแนน/ความปลอดภัยใช้ของเดิมทั้งหมด)
> กติกาความปลอดภัยใน CLAUDE.md ข้อ 7 ยังสำคัญกว่าทุกลูกเล่นในเอกสารนี้

---

## 1. แนวคิด

**"แคมปัสนี้มีแก๊งคอลเซ็นเตอร์ซ่อนอยู่ — ช่วยเพื่อนให้รอด"**

- แผนที่ 3D low-poly ของ มจธ. บางมด มีเพื่อน (NPC) กระจายอยู่ตามจุดต่างๆ แต่ละคนกำลังเจอกลโกงหนึ่งแบบ
- แตะเพื่อน → อ่านสถานการณ์ → **สวมบทเป็นเพื่อนคนนั้น** แล้วรับสาย/ตอบแชทเอง (หัวใจการฝึกเดิม: *เรา* เป็นคนโดนกดดัน)
- รอด = เพื่อนคนนั้น "ปลอดภัย" ฉลองบนแผนที่ · โดนหลอก = X-Ray สอนว่าพลาดตรงไหน แล้วลองใหม่ได้
- ลูกเล่นทุกอย่าง **ให้รางวัลพฤติกรรมที่ถูก**: วางสาย/บล็อกเร็วหลังเห็นสัญญาณอันตราย, ไม่หลุดข้อมูล, พูดถึงการโทรกลับเบอร์ทางการ/1441

## 2. วงจรการเล่น (core loop)

```
แผนที่แคมปัส ──แตะ NPC──▶ StoryCard ──"สวมบท"──▶ สายเรียกเข้า / แชท
     ▲                                                     │
     │                                                วางสาย / บล็อก
     │                                                     ▼
 NPC ฉลอง / ยังมี "!"  ◀── XP + เหรียญ + ฉายา ◀── Scam X-Ray + คะแนน
```

- ครั้งแรก: ยินยอม (v3) → เลือก avatar → สุ่มฉายา → ทัวร์สั้น 3 ขั้น (แตะ NPC / ปุ่มวางสาย / X-Ray)
- เป้าหมายระยะยาว: ช่วยครบทุกคน (`ช่วยเพื่อนแล้ว 3/6`), เลเวลขึ้น, เหรียญครบ, ขึ้นบอร์ด

## 3. NPC และด่าน

ชื่อเล่น/บุคลิกเป็นตัวละครสมมติ · สถานที่ใช้ "ประเภท" ไปก่อน แล้วแมปเป็นสถานที่จริงเมื่อ Nut ส่งรายชื่อ (ข้อ 9)

| NPC | สถานที่ (ประเภท) | ด่าน | ช่องทาง | ความยาก | hook บนป้าย |
|---|---|---|---|---|---|
| น้องมิ้นท์ ปี 1 | หอพัก | `bank-account-hacked` | 📞 | ง่าย | "ธนาคารโทรมาบอกบัญชีโดนแฮ็ก!" |
| น้องบอส ปี 1 | ลานกิจกรรม | `online-job-chat` (ใหม่) | 💬 | ง่าย | "มีงานกดไลก์ ได้วันละ 500!" |
| พี่ต้น ปี 3 | ตึกเรียน | `police-money-laundering` | 📞 | กลาง | "ตำรวจโทรมาว่าบัญชีพัวพันฟอกเงิน" |
| น้องแพรว ปี 2 | จุดรับพัสดุ | `parcel-illegal-goods` | 📞 | กลาง | "พัสดุชื่อเราโดนตีกลับ มียาเสพติด?!" |
| น้องชีส ปี 2 | โรงอาหาร | `investment-chat` (ใหม่) | 💬 | กลาง | "มีคนชวนลงทุน กำไร 30% ต่อเดือน!" |
| พี่ฟ้า ปี 4 (ฝึกงาน) | หอสมุด | `revenue-tax-refund` | 📞 | ยาก | "สรรพากรจะคืนภาษีให้ด้วย ดีจัง" |

- scenario JSON เพิ่ม `channel: "call" | "chat"` และ `npc: { name, location, hook, avatar }`
- สถานะ NPC ต่อผู้เล่น: `danger` (ยังไม่เคยช่วย, มี "!") → `saved` (เคยรอดอย่างน้อย 1 ครั้ง, ฉลอง ✨)
- **"ช่วยสำเร็จ"** = ได้เกรด `strong` หรือ `close` และไม่ยอมทำตามคำขอเงิน และ **ไม่ใช่การไม่รับสายตั้งแต่แรก** (ไม่รับสายปลอดภัยที่สุดในชีวิตจริง แต่ในเกมยังไม่ได้ฝึก — ได้คะแนนเต็มใน X-Ray แต่ไม่นับว่าช่วยเพื่อน)

## 4. ตัวตนผู้เล่น

- **Guest (ค่าเริ่มต้น):** Supabase anonymous sign-in อัตโนมัติ ไม่ต้องกรอกอะไร
- **Login Google (ไม่บังคับ):** `linkIdentity` กับบัญชี guest เดิม → ความคืบหน้าอยู่ครบ เล่นต่อได้ทุกเครื่อง
  - Google นี้มีบัญชีอยู่แล้ว → เข้าบัญชีนั้น (แจ้งก่อนกดว่าความคืบหน้า guest บนเครื่องนี้ไม่ย้าย — v1)
- **ที่แสดงต่อคนอื่นมีแค่:** avatar + **ฉายา** (ข้อ 6) + เลเวล — ไม่มีชื่อจริง/อีเมลบนหน้าใดเลย
- เก็บใน Supabase: `profiles`, `plays`, `badges` (ไม่มี transcript) · อีเมลอยู่ในระบบ Auth ของ Supabase เท่านั้น
- consent v3 เพิ่มข้อ: "ถ้า login ด้วย Google ระบบจะเก็บอีเมลไว้ยืนยันตัวตน ไม่แสดงต่อผู้อื่น"

## 5. XP / เลเวล / กันฟาร์ม

`lib/game/progression.ts` (pure function + test) คิดจาก `ResultPayload` ที่ server เซ็นแล้วเท่านั้น

| ที่มา | XP |
|---|---|
| เกรด strong / close / scammed | 100 / 60 / 20 |
| วางสายภายในเวลาผ่อนผันหลังจุดอันตราย | +30 |
| ไม่หลุดข้อมูลเลย | +20 |
| พูดว่าจะโทรกลับเบอร์ทางการ / 1441 | +20 |
| ไม่รับสายตั้งแต่แรก | 30 (แทนทั้งหมดข้างบน) |

- **กันฟาร์ม:** ด่านเดิมในวันเดียวกัน (เวลาไทย) ครั้งที่ 1 = 100%, ครั้งที่ 2–3 = 50%, ครั้งที่ 4+ = 0 · ด่านที่เคยช่วยสำเร็จแล้ว ครั้งต่อๆ ไปได้ 50%
- **เลเวล:** ใช้ XP `100 × n` เพื่อขึ้นจากเลเวล n → n+1 (สะสม: เลเวล 2 = 100, 3 = 300, 4 = 600 …)
- ชื่อระดับ: 1 นักศึกษาใหม่ · 3 ผู้เริ่มรู้ทัน · 5 นักสืบบางมด · 8 ผู้พิทักษ์แคมปัส · 12 ตำนานสายตัดไว

## 6. ฉายา (alias) และฉายาพฤติกรรม (title)

**ฉายา = ชื่อที่แสดงบนบอร์ด** ประกอบจากชิ้นส่วนที่กำหนดไว้เท่านั้น (ไม่มีข้อความอิสระ → ไม่ต้องกรองคำหยาบ และระบุตัวคนไม่ได้)

- รูปแบบ: `[คำนำ] + [ตัวตน] + [ฉายาท้าย]` เช่น "ท่านผู้ใจบุญ แห่งบางมด", "จอมยุทธ์ สายตัดไว ไร้เทียมทาน"
- สุ่มใหม่ได้เรื่อยๆ หรือเลือกทีละช่อง · เก็บเป็น index ของชิ้นส่วน (`alias_parts`) server ตรวจว่าอยู่ในรายการ
- ชิ้นส่วนอยู่ใน `lib/game/alias.ts` แก้เพิ่มได้ (ห้ามใส่คำที่เสียดสีกลุ่มคน)

**ฉายาพฤติกรรม (title)** คำนวณจากสถิติ แสดงใต้ฉายา — ขำแต่ไม่ด่า

| title | เงื่อนไข | โทน |
|---|---|---|
| 🛡️ กำแพงเหล็ก | คะแนนเฉลี่ย ≥ 90 (≥ 3 สาย) | ชม |
| ⚡ สายตัดไว | วางสายทันเวลา ≥ 5 ครั้ง | ชม |
| 📈 ล้มแล้วลุก | เคยโดนหลอก แล้วด่านเดียวกันรอบหลังได้ strong | ชม |
| 🤗 ใจดีเกินไป | ยอมทำตามคำขอเงิน ≥ 3 ครั้ง | ขำ |
| 👂 นักฟังตัวยง | วางสายช้ากว่าจุดอันตรายเฉลี่ย > 60 วิ (≥ 3 สาย) | ขำ |
| 📮 หูเบา | ยอมทำตาม ≥ 2 ด่านที่ต่างกัน | ขำ |

## 8. บอร์ด (`/hall`)

แสดง avatar + ฉายา + title เท่านั้น · รีเฟรชตอนเปิดหน้า

1. 🛡️ **ภูมิคุ้มกันแกร่ง** — คะแนนเฉลี่ยสูงสุด (ต้องเล่น ≥ 3 สาย)
2. 📈 **พัฒนาขึ้นมากที่สุด** — คะแนนดีที่สุด − คะแนนสายแรก (≥ 2 สาย)
3. 🤡 **ใจดีที่สุดแห่งบางมด** — ยอมทำตามคำขอเงินบ่อยที่สุด · **เฉพาะคนที่เปิดสวิตช์ "ขึ้นบอร์ดขำ" เอง** (ปิดได้ตลอด)
4. 📊 **สถิติแต่ละด่าน** (ทุกคนรวมกัน ไม่ระบุตัว) — "72% โดนหลอกด่านนี้", วางช้าเฉลี่ย, จำนวนคนเล่น — แสดงใน StoryCard ด้วย

## 9. แผนที่ 3D

- **สถานที่:** Nut ส่งรายชื่อจุดเด่นของ มจธ. บางมด 5–7 แห่ง + รูปอ้างอิง → ผมทำเป็นตึก low-poly แบบ stylize ให้จำได้ (ไม่ใช่โมเดลจริงละเอียด) · **ไม่ใช้โลโก้/ตราทางการ**
- ระหว่างรอ: ใช้ตึกกล่องทั่วไปพร้อมป้ายชื่อประเภทสถานที่
- ของตกแต่ง/ตัวละคร: Kenney (CC0) — ใส่เครดิตในหน้า about
- กล้อง: มุมเฉียงลง หมุนได้จำกัด (ไม่ให้มุดใต้พื้น), pinch zoom, แตะ NPC → บินเข้าหา
- ระหว่างโทร/แชท: **unmount Canvas** คืน GPU/หน่วยความจำให้ไมค์ + AI

**Performance budget (มือถือกลางๆ):** โมเดลรวม < 3 MB (gltf-transform + meshopt), < 60k triangles, texture ≤ 1024px, `dpr` ≤ 1.5, `frameloop="demand"` ตอนนิ่ง, ลด shadow/effect อัตโนมัติด้วย `PerformanceMonitor`, เป้า ≥ 30 fps · `prefers-reduced-motion` → กล้องนิ่ง ไม่มี animation ใหญ่ · ไม่มี WebGL → แผนที่ 2D (SVG) ใช้ข้อมูล NPC/StoryCard ชุดเดียวกัน

## 10. แชทจำลอง (สรุป — รายละเอียดตอน Phase 3)

- หน้าตาแอปแชททั่วไป (ไม่เลียนแบบ LINE/Messenger), ปุ่ม **"บล็อก/รายงาน"** = วางสาย
- AI ตอบเป็น JSON `{ messages: [{ text, prop? }] }` — prop ได้แค่ของปลอมที่วาดเอง: การ์ดลิงก์โดเมน `.example`, สลิปปลอมไม่มีโลโก้ธนาคาร, กราฟกำไรปลอม
- คะแนนแชท: หักตามจำนวนข้อความคนร้ายหลังจุดที่ควรบล็อก (แทนวินาที)

## 11. Art direction (ร่าง — Nut ปรับได้)

- โลก: กลางวันโทนพาสเทลอุ่น, เงานุ่ม, ต้นไม้กลม, ทางเดินอิฐ · NPC chibi หัวโต · ป้าย "!" สีแดงเด้งเป็นจังหวะ
- UI ทับแผนที่: การ์ดมุมโค้ง glass blur บางๆ, ปุ่มใหญ่นิ้วโป้งกดง่าย
- ตอนโทร/แชท: ตัดเข้าโหมดมืดแบบหน้าจอโทรศัพท์ (token เดิม) — ความต่างช่วยให้รู้สึก "เข้าสถานการณ์จริง"
- X-Ray: ธีม "สแกน" สีฟ้า-เขียวเรืองแสง · ผลลัพธ์: confetti (strong) / glitch "SCAMMED" (scammed)
